PES Arena V1.4.31 - Tournament Test Mode

1. Deploy source V1.4.31.
2. Supabase SQL Editor: chạy docs/update_tournament_test_mode_v1_4_31.sql.
3. Admin > Giải đấu > mở Tournament Test Mode.
4. Nhanh nhất: bấm "Mô phỏng toàn giải 16 HLV".
5. Dùng "Xem với tư cách" để chuyển Admin / Người ngoài / Test HLV 01..16.
6. Xong test bấm "Xóa dữ liệu Test".

Test Mode lưu trong tournament_test_sandboxes riêng.
Không tạo user giả thật; không ghi public.matches; không cộng RP/Zcoin/Lucky Box; không sửa giải thật.
