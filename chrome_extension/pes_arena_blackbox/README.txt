PES ARENA BLACK BOX DEBUGGER v1.0.0

Cài đặt:
1. Mở chrome://extensions
2. Bật Developer mode
3. Load unpacked -> chọn thư mục pes_arena_blackbox
4. Mở PES Arena rồi bấm biểu tượng tiện ích.

Chức năng:
- Giữ tối đa 60 giây sự kiện gần nhất trên chính tab đang test.
- Bắt JS error, unhandled rejection, console.error, fetch status/thời gian, click nút/link.
- Lưu báo cáo JSON hoặc chụp ảnh màn hình hiện tại.
- Tự che password/secret/token/authorization/cookie/session/Parsec.

Lưu ý:
- Extension là kính hiển vi cho Admin/Test, không thay thế Black Box server.
- Nếu domain production không phải *.vercel.app, hãy thêm domain đó vào matches/host_permissions trong manifest.json.
